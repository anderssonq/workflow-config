The fact, stated plainly and in full. One note, one fact — a note holding three gets
recalled for one and applied for all three.

**Why:** what makes it true, or what broke that made it a rule. Without this the note is
an assertion, and assertions get overridden by whatever the model believes today.

**How to apply:** what to do differently next time, concretely. Without this the note is
trivia that gets read and ignored.

See also [[a-related-note]], [[another-one]].
